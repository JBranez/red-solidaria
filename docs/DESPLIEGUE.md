# Despliegue

La guía vigente para publicar el sistema completo se encuentra en [DESPLIEGUE_DOCKER.md](DESPLIEGUE_DOCKER.md).

El despliegue recomendado usa GitHub para versionado y GitHub Actions para CI/CD, Docker Compose para SQL Server, FastAPI y Angular, y Caddy para HTTPS y proxy inverso. Los pasos se ejecutan desde Windows PowerShell.
